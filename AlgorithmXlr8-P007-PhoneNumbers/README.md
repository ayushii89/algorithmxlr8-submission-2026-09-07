# Phone Numbers

**Difficulty:** `Easy`

## Problem

A phone number is a string of length 11 matching pattern 8xxxxxxxxxx. Given n digit cards forming a string, find the maximum number of phone numbers that can be formed, using each card in at most one phone number.

Read n, then the string of n digits. Output the maximum number of phone numbers that can be formed, or 0 if none can be made.

## Examples

### Example 1

**Input**
```
11
00000000008
```
**Output**
```
1
```

### Example 2

**Input**
```
22
0011223344556677889988
```
**Output**
```
2
```

### Example 3

**Input**
```
11
31415926535
```
**Output**
```
0
```
