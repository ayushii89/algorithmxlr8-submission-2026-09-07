# Team

**Difficulty:** `Easy`

## Problem

A team of 3 people is looking at n problems. For each problem, each of the 3 members gives an opinion of 0 or 1, where 1 means they think they can solve it. The team decides to code a problem if at least 2 of the 3 opinions are 1.

Read an integer n, then n lines each with 3 integers (0 or 1). Print one integer, the number of problems the team decides to code.

## Examples

### Example 1

**Input**
```
n = 3
1 1 0
1 1 1
1 0 0
```
**Output**
```
2
```

**Explanation:** The first two rows have a sum of at least 2. The third row sums to 1, so it is not counted.
