# Translation

**Difficulty:** `Easy`

## Problem

You are given two words, s and t, made of lowercase Latin letters. Check whether t is exactly the reverse of s.

Read s on the first line and t on the second line from standard input. Print "YES" if t equals the reverse of s, otherwise print "NO".

## Examples

### Example 1

**Input**
```
s = code, t = edoc
```
**Output**
```
YES
```

**Explanation:** Reversing code gives edoc, which matches t exactly.

### Example 2

**Input**
```
s = code, t = code
```
**Output**
```
NO
```

**Explanation:** Reversing code gives edoc, which does not match t.
