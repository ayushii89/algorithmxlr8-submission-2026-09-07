# Protect Sheep

**Difficulty:** `Easy`

## Problem

Given an R x C grid with sheep (S), wolves (W), and empty cells (.), place dogs (D) in empty cells so no wolf can reach any sheep by moving orthogonally through empty cells. Output any valid grid, or 'No' if impossible.

Read R, C, then R lines of the grid. Print 'Yes' followed by the resulting grid, or 'No'.

## Examples

### Example 1

**Input**
```
6 6
..S...
..S.W.
.S....
..W...
...W..
......
```
**Output**
```
Yes
DDSDDD
DDSDWD
DSDDDD
DDWDDD
DDDWDD
DDDDDD
```

### Example 2

**Input**
```
1 2
SW
```
**Output**
```
No
```
